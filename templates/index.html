CRISP-DM 跨產業資料探勘標準流程架構

Cross-Industry Standard Process for Data Mining 在本洪澇預測專案之六大階段落地實現

01

Business Understanding (商業/領域理解)

核心目標：量化氣象、地貌與基礎建設等 20 種因子對洪澇發生率之邊際影響，提供水利防汛部門事前防災預警決策依據。

  • 應用對象：防災應變中心、水務局工程規畫處、巨災保險承保精算。
  • 成效指標 (KPI)：回歸模型擬合優度 R² > 0.85，顯著降低高風險事件漏報率。
  • 決策價值：透過特徵係數評估各項基礎工程（如清淤、管網改建）的防洪邊際效益。
02

Data Understanding (資料理解)

資料來源：Kaggle Playground Series s4e5（符合 10~20 個特徵之作業嚴格規範）。

  • 樣本維度：5,000 筆觀測值，20 個數值特徵，1 個連續目標 (FloodProbability)。
  • 目標分布：均值 0.4928，標準差 0.0525，分布範圍 [0.322, 0.686]，近似常態。
  • 缺失值檢驗：全欄位 0 缺失值，無極端偏斜離群值。
  • 相關性檢視：單一特徵與目標相關係數介於 0.16 ~ 0.24 之間，綜合加權具有強線性關係。
03

Data Preparation (資料準備)

嚴謹資料工程：防範資訊外洩 (Data Leakage) 與共線性干擾。

  • 資料集劃分：80% 訓練集 (4,000 筆)，20% 測試集 (1,000 筆)，設定固定種子 42。
  • 共線性檢驗 (VIF)：計算各特徵之 Variance Inflation Factor，所有 VIF 介於 1.002 ~ 1.006，遠低於臨界值 5.0，各特徵近乎正交獨立。
  • 標準化/縮放：多元線性回歸保留原始物理量以維護係數直觀可解釋性。
04

Modeling (模型建置與特徵選擇)

多元線性回歸體系：比較普通最小平方法 (OLS) 與特徵篩選技術。

  • 基準模型：OLS (全 20 特徵) 達成 Test R² = 0.8792。
  • 特徵選擇 (RFE)：依據遞迴特徵消除選出 Top 14 特徵（完美滿足題目 13 < 特徵 < 40 條件）。
  • 正規化模型：Ridge Regression (L2) 與 Lasso Regression (L1)，驗證模型泛化能力與參數收縮穩定性。
05

Evaluation (評估與回歸假設檢定)

全面統計驗證：檢核經典多元線性回歸五大基本統計假設。

  • 指標度量：R² (0.8792), Adjusted R² (0.8767), RMSE (0.01808), MAE (0.01436)。
  • 五大假設全數達標：線性性、殘差常態性 (Jarque-Bera p=0.4569)、同質變異性 (p=0.7641)、獨立性 (Durbin-Watson=1.9793)、無多重共線性 (Max VIF=1.0065)。
  • 區間估計：導出 95% 信賴區間 (CI) 與預測區間 (PI) 封閉解公式。
06

Deployment (系統部署與應用)

落實互動預警產品：將模型封裝為現代化響應式 Web 預測決策介面。

  • RESTful API：Flask 伺服器提供即時單筆/批次推論與區間估算端點。
  • 情境模擬器：內建季風暴雨、韌性海綿城市等情境快速一鍵切換。
  • 視覺化決策儀表板：整合 Chart.js 即時雷達與風險因子邊際貢獻瀑布圖。

CRISP-DM 跨產業資料探勘流程：50 Startups 新創投資分析

遵循 CRISP-DM 國際標準，以 50 間新創企業真實營運財務數據落實多元線性回歸全生命週期

01

Business Understanding (商業/領域理解)

核心目標：量化新創公司各項資本配置（研發、行政、行銷、地域）對年度淨利之邊際報酬，協助創投基金 (VC) 制定最佳資金注資決策。

  • 應用對象：創投合夥人、天使投資人、新創財務長 (CFO)。
  • 成效指標 (KPI)：回歸模型擬合優度 R² > 0.90，顯著辨別最具投資回報率之支出類別。
  • 決策價值：精準驗證「研發投入對新創獲利的決定性正相關」，打破「盲目擴大行銷能彌補研發不足」之迷思。
02

Data Understanding (資料理解)

資料來源：Avik-Jain 100-Days-Of-ML-Code 公開資料集 (50_Startups.csv)。

  • 樣本維度：50 筆美國新創公司觀測值，4 個輸入變數，1 個連續目標 (Profit)。
  • 數值特徵：`R&D Spend` ($0~$165k)、`Administration` ($51k~$182k)、`Marketing Spend` ($0~$471k)。
  • 類別特徵：`State` (New York: 17家, California: 17家, Florida: 16家)。
  • 目標分布：均值 $112,012，標準差 $40,306，最小值 $14,681，最大值 $192,261。
03

Data Preparation (資料準備)

關鍵工程：類別變數轉換與虛擬變數陷阱 (Dummy Variable Trap) 排除。

  • One-Hot Encoding：將 3 類別 State 轉換為 2 個 Dummy 變數（以 California 為基準對照組），完全避免多重共線性 (Multicollinearity)。
  • 缺失值處理：全數欄位 0 缺失值；研發支出為 0 者保留為真實無研發新創代表樣本。
  • 資料集劃分：80% 訓練集 (40 筆)、20% 測試集 (10 筆)，隨機種子固定保證重現性。
  • VIF 共線性檢定：各數值欄位 VIF 均小於 2.5，遠低於 5.0 警戒值。
04

Modeling (模型建置與特徵選擇)

演算法實作：多元線性回歸 (OLS) 與逐步向後淘汰法 (Backward Elimination)。

  • 全特徵 OLS 模型：包含所有支出與州別虛擬變數，獲得基準擬合力。
  • 向後淘汰 (Backward Elimination)：逐一剔除 p > 0.05 不顯著特徵（Step 1: 剔除 State_FL p=0.990，Step 2: 剔除 State_NY p=0.953，Step 3: 剔除 Administration p=0.602）。
  • 最優精簡模型：`R&D Spend` + `Marketing Spend` 雙特徵，僅用 2 個特徵保留 99.9% 預測力！
05

Evaluation (模型評估與五大假設)

統計診斷：高達 R² = 0.9508，五大古典回歸假設全數嚴格通過。

  • 預測精度：Test R² = 0.9485、Adjusted R² = 0.9452、Test RMSE = $9,120。
  • 五大假設：線性性 (通過)、殘差常態性 JB p=0.62 (通過)、同質變異 BP p=0.38 (通過)、Durbin-Watson = 2.05 (通過)、無多重共線性 (通過)。
  • 區間推導：以封閉式矩陣推導出 95% 信賴區間 (CI) 與 95% 預測區間 (PI)。
06

Deployment (系統部署與應用)

落實閉環：互動式創投投資組合模擬決策系統。

  • 前端毫秒級推論：即時滑動 3 大支出滑桿與州別，動態輸出預測利潤與 CI/PI 帶。
  • 創投決策建議：根據獲利等級與區間預測，自動給予投資評等與資金調配建議。
  • 跨平台支援：同時支援本機 Flask 微服務與純靜態 GitHub Pages 離線運算。

Q1: 在 50 Startups 資料集中，State 欄位為類別型變數（New York, California, Florida），進行多元線性回歸時應如何正確處理？
GPT 回覆與採納決策：必須採用 One-Hot Encoding 建立虛擬變數 (Dummy Variables)，但切記不能建立 3 個虛擬變數，否則會陷入「虛擬變數陷阱 (Dummy Variable Trap)」，導致設計矩陣 X 列完全共線性 (Perfect Multicollinearity) 而無法求逆。正確做法是保留 2 個虛擬變數（如 State_Florida, State_New York），將 California 設為基準對照組。

GPT 回覆與採納決策：p = 0.602 遠大於 0.05 顯著水準，代表無法拒絕「該係數母體為 0」的虛無假設。在商業意涵上，行政費用（如人事會計、辦公室租金）屬於新創維持運作的間接管理成本，本身不直接創造商業價值或產品競爭力。向後淘汰法建議將其自最終預測模型中剃除。
Q3: 針對金額預測的多元線性回歸，如何計算 95% 信賴區間 (CI) 與預測區間 (PI)？兩者寬度為何不同？
